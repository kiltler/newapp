# Changelog

Все заметные изменения проекта фиксируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
проект использует [семантическое версионирование](https://semver.org/lang/ru/) —
`МАЖОРНАЯ.МИНОРНАЯ.ПАТЧ` (например `1.2.3`):

- **МАЖОРНАЯ** — несовместимые изменения (сломается привычный сценарий, нужна
  миграция/переучивание). `1.x.x → 2.0.0`.
- **МИНОРНАЯ** — новая функциональность без поломки старого. `1.0.x → 1.1.0`.
- **ПАТЧ** — исправления ошибок и мелкие правки. `1.0.0 → 1.0.1`.

Единый источник версии — `app/__init__.py` (`__version__`). Она показывается
в шапке рядом с «NVR Monitor» и подставляется в шаблоны как `{{ app_version }}`.

## [1.0.0] — 2026-07-06

Первый стабильный релиз. Проект уже работает с реальными регистраторами.

### Добавлено
- Модуль **Заселения**: ночная выгрузка субпотока с камер въезда/ресепшена
  в локальное хранилище, просмотр клипов x1–x16, журнал заселений, настройка
  через веб, пароли шифруются (Fernet, ключ `NVR_SECRET_KEY`).
- Модуль **Автобусы**: ручной учёт ротации дисков, карточки со статусами,
  журнал замен, статистика.
- Обновлённый тёмный дизайн (бирюзовый акцент), дашборд с диаграммами.

### Изменено
- Автобус с отмеченной проблемой всегда показывается красным.

### Удалено
- Таймер «пора менять диск» в модуле Автобусы.
- Кнопка выгрузки «За сегодня» на странице клипов Заселений.
